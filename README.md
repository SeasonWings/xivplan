# AstroPlan

为诛仙世界提供适配的MMO战术交流板

本项目是对@SPJP xivplan项目的Fork&二开,加入了部分《诛仙世界》相关的功能&元素组件

同时针对使用痛点加入了客制化功能

项目个人线上环境： https://xivplan.mapleshuzuko.site

## 如何使用

- 点击**帮助**（或按F1）查看UI说明和键盘鼠标操作快捷方式
- 左侧面板可调整战术板外观并通过拖动对象添加到竞技场
- 点击场景中的对象可选择它，拖动句柄调整大小或移动
- 右侧面板显示当前场景中所有对象，可删除或调整图层顺序
- 顶部可添加新步骤并切换步骤

### 保存与分享

- 方案默认保存在本地浏览器
- Chromium 浏览器支持直接保存为文件
- 点击 **分享** 可生成分享链接，或下载 `.xivplan` 文件分享
- 你也可以注册AstroPlan账户来向战术板社区分享你的作品
